## Представление транзакции

Каждая транзакция содержит поля:

- `id` — идентификатор;
- `date` — дата и время;
- `amount` — сумма;
- `category` — категория;
- `description` — описание.

Пример объекта:

```javascript
{
    id: "1",
    date: "01.01.2025",
    amount: 100,
    category: "Еда",
    description: "Покупка продуктов"
}
```

## Отображение транзакций

Транзакции отображаются в HTML-таблице.

Таблица содержит столбцы:

- дата и время;
- категория транзакции;
- краткое описание;
- кнопка удаления.

Если сумма положительная, строка становится зеленой.

Если сумма отрицательная, строка становится красной.

Для краткого описания выводятся первые четыре слова.

Пример:

```javascript
description.split(" ").slice(0, 4).join(" ");
```

## Добавление транзакции

Для добавления транзакции используется HTML-форма.

После отправки формы:

1. создается объект транзакции;
2. транзакция добавляется в массив;
3. строка добавляется в таблицу;
4. обновляется общая сумма.

Пример создания объекта:

```javascript
const transaction = {
    id: generateId(),
    date: formatDate(new Date()),
    amount: amount,
    category: category,
    description: description
};
```

## Удаление транзакции

В каждой строке таблицы есть кнопка удаления.

При нажатии:

- строка удаляется из таблицы;
- транзакция удаляется из массива;
- обновляется общая сумма.

Для обработки используется делегирование событий.

Пример:

```javascript
table.addEventListener("click", function (event) {
});
```

## Подсчет общей суммы

Функция `calculateTotal()` считает сумму всех транзакций.

Пример:

```javascript
export function calculateTotal() {
    return transactions.reduce(function (sum, transaction) {
        return sum + transaction.amount;
    }, 0);
}
```

После добавления или удаления транзакции сумма обновляется:

```javascript
totalElement.textContent = calculateTotal();
```

## Полное описание транзакции

При нажатии на строку таблицы полное описание отображается в отдельном блоке.

Пример:

```javascript
fullDescription.textContent = transaction.description;
```

## Валидация формы

Перед добавлением транзакции проверяется заполнение всех полей.

Если поля пустые, выводится сообщение об ошибке.

Пример:

```javascript
if (amountInput.value === "" || category === "" || description === "") {
    errorElement.textContent = "Заполните все поля";
}
```

## Контрольные вопросы

### 1. Каким образом можно получить доступ к элементу на веб-странице с помощью JavaScript?

Для доступа к элементам используются методы DOM.

Пример:

```javascript
document.getElementById("amount");
```

Также можно использовать:

```javascript
document.querySelector("form");
```

### 2. Что такое делегирование событий и как оно используется для эффективного управления событиями на элементах DOM?

Делегирование событий — это способ обработки событий через родительский элемент.

В данной работе обработчик события установлен на таблицу:

```javascript
table.addEventListener("click", function (event) {
});
```

Это позволяет обрабатывать клики по кнопкам удаления и строкам таблицы.

### 3. Как можно изменить содержимое элемента DOM с помощью JavaScript после его выборки?

Содержимое можно изменить через:

```javascript
textContent
```

или

```javascript
innerHTML
```

Пример:

```javascript
totalElement.textContent = calculateTotal();
```

### 4. Как можно добавить новый элемент в DOM дерево с помощью JavaScript?

Элемент создается через:

```javascript
document.createElement()
```

Пример:

```javascript
const row = document.createElement("tr");
```

После этого элемент добавляется в DOM:

```javascript
tbody.appendChild(row);
```
